# Amaç

SmartBudget AI'yi ilk kez kullanan kullanıcı uygulamaya login olduktan sonra temel ekranların ne işe yaradığını anlamalıdır.

Ayrıca kullanıcı tutorial'ı daha sonra tekrar görmek isterse ana uygulama ekranlarının sağ üst köşesinde bulunan `?` yardım butonundan tekrar açabilmelidir.

# 2. Kullanıcı Bazlı Saklama

Mevcut flutter_secure_storage kullanılabilir.

Tutorial'ın görülme bilgisini mümkün olduğunca kullanıcı bazlı sakla.

Örneğin mevcut authenticated email bilgisi kullanılarak normalize edilmiş bir kullanıcı anahtarıyla:

tutorial_seen_v1_<user>

benzeri internal storage yaklaşımı uygulanabilir.

Ancak:

- password saklama
- JWT dışındaki hassas veri ekleme
- backend değişikliği

yapma.

Uygulamada birden fazla farklı kullanıcı login olursa her kullanıcının ilk kullanım deneyimi bağımsız olmalıdır.

Tutorial version key kullan:

v1

Böylece gelecekte tutorial ciddi şekilde değişirse yeni versiyon gösterilebilir.

# 8. İlk Login Tetikleme

Tutorial login ekranının üstünde açılmamalıdır.

Akış:

Login başarılı
→ MainShell authenticated state
→ ilk frame/render güvenli şekilde tamamlanır
→ tutorial görülmemişse tutorial açılır

Build sırasında doğrudan showDialog/showModal çağrısı yaparak Flutter lifecycle problemi oluşturma.

Gerekirse:

WidgetsBinding.instance.addPostFrameCallback

veya mevcut mimariye uygun güvenli yaklaşım kullan.

Tutorial her rebuild'de tekrar tekrar açılmamalıdır.
